# Trademark policy

The Apache-2.0 licence covers the code. It does not cover the names and logos.

**You may, without asking:**

- state truthfully that your software is compatible with, built on, or a plugin for
  Frontier ("OpenFOAM connector for Frontier", "works with Frontier datasets");
- use the name to refer to the project in articles, talks, courses and documentation;
- distribute unmodified builds of this repository under its own name.

**Please ask first (oss@dimensionlab.org):**

- using "Frontier" or "DimensionLab" in the name of a product, company, domain or package
  (package names on PyPI and crates.io starting with `frontier-` are reserved for packages
  published from the official repositories; community plugins use the form
  `frontier-connector-<name>` only after registration in the plugin index, or any name of
  the form `<yours>-frontier`);
- using the logos;
- distributing a modified build under the original name.

**Not allowed:** anything that suggests endorsement by, or affiliation with, DimensionLab
where none exists, or that could confuse users about which distribution is the official one.

Forks are welcome; give them their own name.
