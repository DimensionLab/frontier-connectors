# frontier-connectors-oss

Install the open-tool and neutral-format plugins: OpenFOAM, VTK, CGNS, Code_Saturne,
Nek5000, Palabos, PyFR, ParaView Catalyst, array stores, meshio, geometry, tabular files
and EnSight Gold interchange files. These plugins do not require a commercial solver.

```bash
pip install frontier-connectors-oss
```

Each plugin is also an independent distribution. Vendor integrations are developed in
the Frontier monorepo and will be published separately when ready.
